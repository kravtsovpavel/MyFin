# MyFin

Личный финансовый трекер с авторизацией через Google и синхронизацией данных в Supabase.

**Приложение:** [kravtsovpavel.github.io/MyFin](https://kravtsovpavel.github.io/MyFin/)

## Возможности

- учёт доходов и расходов;
- категории и месячный бюджет;
- аналитика и календарь операций;
- фильтрация и постраничный просмотр;
- экспорт данных в Excel;
- адаптивный интерфейс для компьютеров и смартфонов.

## Технологии

Vanilla JavaScript, HTML, CSS, Supabase, Chart.js и SheetJS.

## Локальный запуск

```bash
python -m http.server 8000
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000).

Для собственного проекта Supabase скопируйте `js/config.example.js` в
`js/config.js` и укажите URL проекта и его publishable key. Схема базы находится
в `supabase-setup.sql`.

Проверка регрессий:

```bash
node tests/regression.test.js
```

## Безопасность

- Данные разных пользователей изолированы политиками Row Level Security.
- Клиентский `sb_publishable_...` ключ не является секретом и предназначен для
  использования в браузере.
- Никогда не добавляйте в репозиторий `service_role` ключи, OAuth Client Secret,
  пароли базы данных и другие закрытые токены.

Публичная версия автоматически развёртывается на GitHub Pages после изменений
в ветке `main`.
